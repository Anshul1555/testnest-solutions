## 🔍 Technical SEO & Performance Architecture

This application is engineered for top search engine visibility (Google, Bing, Yahoo, DuckDuckGo) and social graph discoverability:

- **JSON-LD Schema.org Knowledge Graphs**:
  - `Organization` & `ProfessionalService` entities with founder, geocoding, contact channels, and service catalogs.
  - `WebSite` specification with canonical URL declarations.
  - `FAQPage` rich snippet schema targeting high-intent QA search queries.
  - `ItemList` service catalogue.
- **Search Engine Directives**:
  - Valid `sitemap.xml` with image metadata indexing.
  - Custom `robots.txt` allowing full crawler discovery.
  - Canonical link declaration preventing duplicate indexing issues.
- **Social Graph Protocol**:
  - Open Graph (`og:*`) 1200x630 card tags with verified image dimensions.
  - Twitter Card (`twitter:*`) `summary_large_image` tags.
- **Core Web Vitals & Performance**:
  - Optimized lightweight logo and touch icons reducing payload by >99%.
  - Semantic HTML markup and prerendered crawler fallback content for instant First Meaningful Paint.
  - PWA Web App Manifest (`site.webmanifest`).
  - Responsive layout avoiding Cumulative Layout Shift (CLS).
